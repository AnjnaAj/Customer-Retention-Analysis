# Customer Retention Analysis

## Objective
Analyze customer behavior and identify patterns affecting customer retention and churn.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Work
- Cleaned and transformed raw data
- Built data model and relationships
- Created DAX measures and KPIs
- Designed interactive dashboard

## Outcome
Generated insights to improve customer retention strategies and reduce churn.
